[Paper — DeepSeek-V3 Technical Report](https://arxiv.org/abs/2412.19437?utm_source=chatgpt.com)

你最终应该得到的是：

$$
\boxed{\text{quality / GPU-hour / memory / bandwidth / dollar}}
$$

## 最核心的 syllabus，其实只有 12 个节点

如果再压一层，我只保留：

1. **3Blue1Brown Linear Algebra + Stat110 selective**
2. **CS336 selective**
3. **Transformer → Kaplan → Chinchilla**
4. **DeepSeek V2 → V3 → R1 → test-time scaling**
5. **DDIA 2e selective**
6. **一个 agent + eval prototype**
7. **MS&E435**
8. **NBER Transformative AI selective**
9. **Generative AI at Work + Jagged Frontier + METR**
10. **Superforecasting + Expectations Investing**
11. **Teece + 7 Powers**
12. **Camuffo + The Mom Test**

算法则作为：

> **CP Handbook + Sedgewick + USACO Guide**

旁路维护。

这套结构我认为已经接近你的 **efficient frontier**：再减少会产生明显知识缺口，再增加大概率开始进入 intellectual consumption。真正的升级不是学第13门课，而是让每个资源都产生一个真实 output：

$$
\boxed{
Learning
\rightarrow
Model
\rightarrow
Prediction
\rightarrow
Experiment/Valuation
\rightarrow
Decision
}
$$

而不是：

$$
Learning\rightarrow More\ Learning.
$$

对你未来投资、独立研究和机会驱动创业而言，这个转换机制本身，比 syllabus 中任何单项资源都重要。
