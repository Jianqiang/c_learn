### 第三个口径：剔除新 AI 产品

`[S]` 官方公告原文：**若剔除新 AI 产品贡献，non-IFRS 经营盈利为 861 亿元，同比增长 19%；经营利润率由去年的 39% 提升至 42%。**
`[S]` 脚注定义：**新 AI 产品以 Hy、元宝、CodeBuddy、WorkBuddy 及小微为主。**

> 由此可推得的算术差额：861 − 756 = **约 105 亿元/季度**。
> 这是公告并列披露的两个数字之差，**不是**官方单独披露的"AI 业务亏损额"——它同时包含这些产品的收入、成本与费用净影响。使用时请标注口径。

`[S]` 本土市场游戏 **473 亿，+17%**（《三角洲行动》《无畏契约》《无畏契约：源能行动》《洛克王国：世界》贡献显著）

### 营销服务
`[S]` 增长归因（公告原文三条）：① AI 驱动的**广告推荐模型**优化（决定向每位用户每次曝光展示什么）；② 智能投放产品矩阵**腾讯营销 AIM+** 升级（帮广告主购买优质曝光量）；③ **微信生态内闭环营销能力整合**（小游戏、微信小店等更有效投放于腾讯管理的广告资源）
`[S]` 毛利率 55%→57%，公告说明季节性收入增长抵销了成本增加，**成本增加包含 AI 基础设施相关的折旧与运营成本**
`[S]` 视频号 2Q2026 总用户使用时长同比 **+20% 以上**
`[M]` 广告**加载率仍有进一步提升空间**

### 金融科技及企业服务
`[S]` 金融科技服务收入增长来自：商业支付、理财及消费贷款服务
`[S]` 企业服务收入增长主要来自云服务，归因：AI 相关服务需求提升、国际市场持续扩张、**更为有利的定价环境**

## 6. AI 三层结构（管理层框架，原文）

`[M]` 马化腾表述：在**智能、应用、基础设施**三个层面构建 AI 赋能的新腾讯。

| 层 | 内容 | 等级 |
|---|---|---|
| 智能层 | Hy3 正式版 2026 年 7 月发布，性能较 preview 大幅提升 | `[S]` |
| | 按 OpenRouter **token 消耗量**计，Hy3 自推出持续位列**全球前三** | `[M]` |
| 应用层 | WorkBuddy（AI 办公）、CodeBuddy（AI 编程）"突破性用户增长"，各自领域中国领先 | `[M]` |
| | WorkBuddy 用户通过**订阅和充值购买 token** 付费，付费意愿强烈；领先归因于 harness（智能体调度）工程能力、模型选择丰富、技能库 | `[M]` |
| | 微信内 AI 智能体**小微**近数周开始小范围灰度测试，由定制模型 **WeLM** 驱动（专注隐私、微信场景、推理效率） | `[S]` |
| 基础设施层 | 大幅增加算力采购 | `[S]` |
| | 腾讯云预计 2026 Q4 部署基于**近封装光学（NPO）**的超算节点 | `[M]` |

### 管理层关于算力经济性的原话
`[M]` 刘炽平：若把算力全部对外出租，资本开支回报**至少超过 30%**。
`[M]` 刘炽平：几个月前预付订购的部分算力，按当前市场价格出售可获**超过 30% 的利润**。
`[M]` 刘炽平：先拿算力自研模型、打磨自有应用，**剩余算力再对外出租**，按顺序长期布局。
`[M]` 本轮 AI 原生业务投入**以一次性为主**，今年底至明年初仍将持续，但**未来不会持续维持高投入规模**。
`[M]` 预计今年底至明年初 GPU 资源将更加充足，从而进一步提升云服务能力。
`[M]` 关注 GPU 算力、**模型即服务（MaaS）**等业务机会，将统筹调配算力资源，兼顾内部模型开发与对外出租。

## 7. 术语表

| 术语 | 含义 |
|---|---|
| **non-IFRS** | 腾讯自定义口径，剔除若干一次性及/或非现金项目（含股份酬金、投资相关损益、无形资产摊销等），**定义可能与其他公司不同** |
| **新 AI 产品** | 公告脚注定义：Hy、元宝、CodeBuddy、WorkBuddy、小微 |
| **算力预付款** | 提前支付以锁定未来算力供应的定金，计入经营现金流出但不计入当期资本开支入账 |
| **MaaS** | Model as a Service，模型即服务 |
| **harness** | 智能体调度工程层 |
| **WeLM** | 驱动"小微"的定制模型 |
| **NPO** | 近封装光学（Near-Package Optics） |
| **AIM+** | 腾讯营销智能投放产品矩阵 |
| **固定汇率** | 剔除汇率波动后的同比口径 |
