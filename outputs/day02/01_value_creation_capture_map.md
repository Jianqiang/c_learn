## 使用说明

这张图要回答的**不是**「这家公司好不好」，而是：

```
价值在哪里被创造 → 谁有能力索取它 → 为什么是这个分配 → 什么会改变这个分配
```

**创造 ≠ 索取。** 一个环节可以创造巨大价值却拿不到（弱 appropriability），
另一个环节可以创造有限价值却拿走大头（控制 cospecialized asset）。
